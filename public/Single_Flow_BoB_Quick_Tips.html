Welcome to BoB - Single Flow Path

BoB - Single Flow Path is a lightweight, URL-based application designed to replace heavy BytePro LOS workflows for post-close shipping duties. This MVP tool automates document collection, validates completeness, and generates individual bundled PDF packages ready for shipping—with increased speed and streamlined value-add functions. Unlike traditional workflows that lock users out of BytePro during bundle processing, BoB operates independently, enabling continuous productivity and allowing shippers to maintain system access for other critical tasks.

Built for Shippers: First-time users can quickly master the 3-step workflow to create shipping-ready PDF bundles without the complexity of legacy systems.

📝 Getting Started (3 Simple Steps) ▼
1
Enter Loan & Select Bundle
Simply enter the loan number and select bundle name - the stacking order grid automatically generates.
  • Subject Loan: Enter the loan number
  • Bundle Name: Choose from ~80 shipping package options from dropdown
  • Auto-Generation: Stacking order grid with document manager upload status automatically populates
  • No additional button click needed - it's that simple!
2
Review Stacking Order Status
Review the automatically generated stacking order to verify document status before building.
  • Grid displays all required documents in predetermined shipping order
  • Found: Documents show count of approved versions in document manager
  • Missing: Documents need attention (not in system or not approved)
  • Note: Use BytePro for document verification/management (direct UI access coming soon)
  • Use filters to focus on specific document categories
3
Build Bundle & Generate Package
Once confident with stacking order state, build the final PDF package ready for shipping.
  • Verify all required documents show "Found" status
  • Click "Build Bundle" to start package generation
  • Bundling spinner indicates process is in progress
  • Download completed package for shipping workflow
📋 Understanding Document Status ▼
Found Document is available and ready to bundle (shows count of approved versions in document manager)
Missing Document is part of master stacking order for this bundle but either does not exist in document manager OR exists without "approved" status
⚡ Key Features & Tips ▼
🔍
Document Categories & Filters
Documents are organized by category with filters to quickly focus on what needs attention.
  • Hide Not Applicable Docs: Automatically filters out documents not required for your specific loan transaction, eliminating clutter and focusing only on relevant missing items
  • Categories: Application, Credit, Property, Income, Assets, Title, Insurance, Closing
  • Filter by Status: All Documents, Missing Docs, Found Docs
  • Category Filter: Narrow view by specific document category
  • Found documents show count of approved versions in document manager
📦
Bundle Preview, Download & Post-Close Upload
Complete the shipping workflow by previewing, downloading, and uploading confirmation documents.
  • Download: Save bundle directly to desktop, temp folder, or local drive for immediate access and shipping delivery
  • Preview: Review complete PDF package with proper page ordering
  • Upload Confirmations: Use upload icon to attach investor delivery confirmations
  • Upload Adhoc Docs: Add specific documents into final PDF output or upload directly to BytePro Docs storage for loan file record-keeping
  • All uploaded documents automatically sync to BytePro Docs storage and link to the loan file
🔄
Refresh & Reload
Use the refresh icon to sync stacking order with the latest document changes made in BytePro.
  • Click the refresh icon after adding or fixing missing documents in BytePro
  • System re-queries for current document availability and approval status
  • Updated statuses and counts refresh in real-time across all filter tabs
  • Build button enables when all required docs are found
✨ Workflow Best Practices ▼
✅
Before Building
  • Verify stacking order grid reflects all applicable docs needed for this bundle. Note: Phase 1 may show some non-applicable docs—full filtering coming with continuous improvements
  • Confirm all required documents show "Found" status with approved versions
  • Review document count in each category filter tab
  • Confirm bundle name matches shipping package requirements
  • Multi-Page Productivity Power: While not a BytePro launch item yet, BoB is designed to let you open multiple browser pages using the direct URL link (see Training & Support section below) to maximize your workflow—build, download, and upload across multiple loans simultaneously! Note: Multiple sessions increase API server calls, which may temporarily impact network performance during active processing
  • Network Performance: Low internet upload speeds (especially outside office/direct network) can slow bundle completion. Test your connection speed by searching "speed test" in Google
⚡
During Build Process & Completion
  • Build time varies based on several factors: stacking order size, number of documents found, simultaneous bundles running, and your internet bandwidth
  • Initial production beta testing shows bundles (50-175 MB) running approximately 2-3 full minutes faster than BytePro counterpart—in some cases completing in under 60 seconds
  • Watch for the bundling spinner indicator showing work in progress
  • Do not navigate away or refresh page during build
  • If build fails, an error message displays with an instant retry option on the spot! Enhanced error messages with detailed troubleshooting guidance coming soon to help you resolve issues even faster
  • Upon Success: Bundle ready! Download your PDF package, verify pages are in order, then click "Clear & Start New" to process your next loan
🔧 Common Issues & Items to Be Aware Of ▼
⚠️
"Stacking Order Failed to Load"
  • Verify loan number is correct (no extra spaces)
  • Confirm loan exists in the system
  • Check network connectivity
  • Try refreshing page and re-entering loan information
  • BytePro Launch Tool Issue? If the launch menu from BytePro isn't working, contact the BytePro team for resolution
  • Pro Tip: Bypass launch issues entirely by opening BoB directly in any web browser using the URL in the Training & Support section below—instant access, no launch menu required! (See Multi-Page Productivity Power in Best Practices for even more ways to maximize this feature)
⚠️
"Bundle Build Failed"
  • Use instant retry option displayed with error message (see Workflow Best Practices for details)
  • Check for documents showing "Missing" status and verify they exist with "approved" status
  • Click "Refresh Stacking Order" and retry build
  • Cross-Platform Advantage: If issue persists, attempt the same loan in BytePro. If BytePro also fails, you've quickly identified it's a systemic gap (not BoB-specific) and can escalate accordingly. Having both platforms helps pinpoint root causes faster—a valuable diagnostic tool while we explore improved error interactions for future releases
⏱️
Large File Upload Timeout (≥ 300MB)
Here's what's happening behind the scenes: Files ≥ 300MB upload successfully to Azure cloud storage (BoB shows success banner ✓), but BytePro's 5-minute database ingestion timeout causes failures during the handoff from cloud to LOS. This is a known architectural challenge we're actively exploring.
  • The Timeline: BoB confirms upload success immediately (because cloud storage succeeded), but BytePro database ingestion runs 5 retry attempts to upload into LOS—a period that can take approximately 5-15 minutes before triggering the email notification
  • Email Alert: "A document could not be sent to LOS after 5 tries. It has been marked as 'Draft'" (includes loan number, document type, title, and timestamp)
  • Action Required: Once email arrives (5-15 min post-upload), you'll need to address the failed upload—one viable solution is splitting the package into files under 300MB and re-uploading
  • Pro Tip: Proactively split files approaching 300MB before uploading to avoid the retry cycle entirely
