Single Flow BoB - Quick Tips

Lightweight Bundle Builder for Post-Close Operations

✓ Now Live in Production

Welcome to Single Flow BoB

Single Flow BoB is a lightweight, URL-based application designed to replace heavy BytePro LOS workflows for post-close shipping duties. This MVP tool automates document collection, validates completeness, and generates individual bundled PDF packages ready for shipping—with increased speed and streamlined value-add functions.

Built for Shippers: First-time users can quickly master the 3-step workflow to create shipping-ready PDF bundles without the complexity of legacy systems.

📝 Getting Started (3 Simple Steps) ▼
1
Enter Loan & Select Bundle
Simply enter the loan number and select bundle name - the stacking order grid automatically generates.
  • Subject Loan: Enter the loan number
  • Bundle Name: Choose from ~80 shipping package options from dropdown
  • Auto-Generation: Stacking order grid with document manager upload status automatically populates
  • No additional button click needed - it's that simple!
2
Review Stacking Order Status
Review the automatically generated stacking order to verify document status before building.
  • Grid displays all required documents in predetermined shipping order
  • Found: Documents show count of approved versions in document manager
  • Missing: Documents need attention (not in system or not approved)
  • Note: Use BytePro for document verification/management (direct UI access coming soon)
  • Use filters to focus on specific document categories
3
Build Bundle & Generate Package
Once confident with stacking order state, build the final PDF package ready for shipping.
  • Verify all required documents show "Found" status
  • Click "Build Bundle" to start package generation
  • Bundling spinner indicates process is in progress
  • Download completed package for shipping workflow
📋 Understanding Document Status ▼
Found Document is available and ready to bundle (shows count of approved versions in document manager)
Missing Document is part of master stacking order for this bundle but either does not exist in document manager OR exists without "approved" status
⚡ Key Features & Tips ▼
🔍
Document Categories & Filters
Documents are organized by category with filters to quickly focus on what needs attention.
  • Categories: Application, Credit, Property, Income, Assets, Title, Insurance, Closing
  • Filter by Status: All Documents, Missing Docs, Found Docs
  • Category Filter: Narrow view by specific document category
  • Found documents show count of approved versions in document manager
📦
Bundle Preview, Download & Post-Close Upload
Complete the shipping workflow by previewing, downloading, and uploading confirmation documents.
  • Preview: Review complete PDF package with proper page ordering
  • Download: Save bundle to local or network drive for shipping delivery
  • Upload Confirmations: Use upload icon to attach investor delivery confirmations
  • Upload Adhoc Docs: Attach shipping-related documents back to loan file
  • All uploaded documents automatically link for record-keeping
🔄
Refresh & Reload
Keep your stacking order up-to-date with the latest document status from the system.
  • Click "Refresh Stacking Order" to reload status
  • System re-queries for current document availability
  • Updated counts reflect in document filter tabs
  • Build button enables when all required docs are found
✨ Workflow Best Practices ▼
✅
Before Building
  • Verify all stacking order documents show "Found" status with approved versions
  • Review document count in each category filter tab
  • Confirm bundle name matches shipping package requirements
  • Multiple Simultaneous Builds: You can open multiple browser tabs to bundle loans simultaneously, but increased API calls may impact performance and extend completion time for all bundles
  • Network Performance: Low internet upload speeds (especially outside office/direct network) can slow bundle completion. Test your connection speed by searching "speed test" in Google
⚡
During Build Process
  • Build time varies based on several factors: stacking order size, number of documents found, simultaneous bundles running, and your internet bandwidth
  • Beta testing shows typical bundles (50-175 MB) often complete in under 30 seconds
  • Watch for the bundling spinner indicator showing work in progress
  • Do not navigate away or refresh page during build
  • If build fails, check error message for specific details
🎯
After Completion
  • Download PDF package to local or network location
  • Verify PDF opens correctly and pages are in order
  • Navigate to Shipper Management for post-close tasks
  • Click "Clear & Start New" for next shipping package
🔧 Common Issues & Items to Be Aware Of ▼
⚠️
"Stacking Order Failed to Load"
  • Verify loan number is correct (no extra spaces)
  • Confirm loan exists in the system
  • Check network connectivity
  • Try refreshing page and re-entering loan information
⚠️
"Bundle Build Failed"
  • Check for documents showing "Missing" status
  • Verify missing documents either don't exist or lack "approved" status
  • Review error message for specific issue
  • Click "Refresh Stacking Order" and retry build
⏱️
Large File Upload Timeout (≥ 300MB)
BytePro has a 5-minute timeout rule. Files ≥ 300MB may upload to Azure cloud successfully but fail to ingest into BytePro database after multiple retries.
  • Email Notification: "A document could not be sent to LOS after 5 tries. It has been marked as 'Draft'"
  • Includes loan number, document type, title, and timestamp
  • Solution: Split large packages into smaller files before uploading
  • No system fix available - file size limitation is a known constraint
